# Internet-Speed-Monitor-for-KDE
a simple plasmoid to show internet speed and usage for KDE plasma.
inspired by: https://github.com/rishuinfinity/InternetSpeedMonitor

## Installation
1. download the file & extract it.
2. open terminal from downloaded folder
4. run `kpackagetool6 --type Plasma/Applet --install org.kde.plasma.internetspeedmonitor.plasmoid`
then `kquitapp6 plasmashell && kstart plasmashell`
